The plugin

Your route, a different atmosphere.

The effect works on the game's finished image just before it appears on screen. Keep playing as usual, with more control over how it looks.

01 / COLOR

Light with character

Adjust contrast, exposure, shadows, and highlights for a more natural or cinematic look.

02 / LUT

A ready-made look

The package includes a LUT, a file that defines how colors appear. You can also use a compatible .cube LUT.

03 / DETAIL

Sharpen to taste

RCAS brings out detail in the image. You can adjust its strength without changing the game's resolution.

How it works

Simple to install. Easy to tune.

The plugin works with DirectX 11 and keeps its controls in a configuration file.

  1. 01

    Back up existing files

    Close the game and save any existing dxgi.dll or NeuralFX folder before installing.

  2. 02

    Extract the package

    Place dxgi.dll and the NeuralFX folder in bin/win_x64, next to the game's executable.

  3. 03

    Make it yours

    Launch the game. To change the look, edit NeuralFX/neuralfx.ini; visual settings reload automatically.

Before installing

Know what to expect.

  • Built for the Windows x64 versions of Euro Truck Simulator 2 and American Truck Simulator using DirectX 11.
  • The effect also changes the game's interface because it processes the finished image.
  • Works with SDR. It does not provide HDR, frame generation, or FSR upscaling.

Quick answers

Clear answers.

Will it increase my FPS?

No. The focus is image quality. Extra processing can affect performance depending on your computer and chosen settings.

Does it upscale with FSR?

No. It uses RCAS sharpening, but it does not increase resolution or generate frames.

Can I change the colors later?

Yes. Adjust the settings in neuralfx.ini and replace the .cube LUT with another compatible one.

Is the source code open?

Yes. The project is on GitHub under the MIT license. Buying the package supports the project.
